# Myarredo — SEO-оптимизация (демо для заказчика)

Демонстрация комплексной SEO-оптимизации интернет-магазина итальянской мебели
**myarredo.by** (Минск, Беларусь; ~68 800 страниц). Репозиторий показывает **систему**
оптимизации (шаблоны + генератор), готовые **страницы-образцы** всех типов и
**стратегию вывода в топ** по всем направлениям.

> Важно: myarredo.by — динамический сайт на CMS. Оптимизация 68k страниц вручную
> не имеет смысла — правки вносятся в **шаблоны** карточки / категории / главной и
> **автозаполняются из полей** товара/раздела, покрывая весь сайт разом. Этот
> репозиторий — доказательство концепции и готовые фрагменты для внедрения в CMS.

## Что внутри

```
demo/                 — готовые оптимизированные страницы-образцы (открыть в браузере)
  home.html                     Главная (интро + блок «лучшей цены» + SEO-текст)
  product-arketipo-lotus.html   Карточка товара (мета, JSON-LD, alt, SEO-текст+FAQ)
  category-*.html               7 категорий: кухни, спальни, гостиные, мягкая мебель,
                                столовая, стулья, освещение — каждая со своим SEO-текстом
templates/            — переиспользуемые фрагменты для вставки в CMS-шаблоны
  category-seo.css.html         Общие стили SEO-блока (в фирменном зелёном стиле сайта)
  product-seo-block.html        SEO-блок карточки (таблицы + 8 FAQ, сворачиваемый)
  product-top-description.html  Верхнее описание карточки (2 абзаца + таблица характеристик)
  home-seo-block.html           SEO-блок главной
  home-promo.html               Блок «Отправьте запрос — гарантия лучшей цены» (5 карточек)
category-blocks/      — SEO-тексты по категориям (контент, генерируемый из полей раздела)
toolkit/              — скрипты аудита и генерации (Node.js)
  crawl.mjs           Полный обход sitemap: статусы, alt, canonical, title/desc, H1, Schema
  aggregate.mjs       Сводка аудита по всему сайту
  build-demo-pages.mjs Генератор демо-страниц категорий
  headers.mjs         Заголовки запросов (обход антибота nginx)
docs/
  SEO-STRATEGY.md     Полная стратегия вывода в топ по всем направлениям
.claude/skills/myarredo-seo/  Навык (skill) для повторяемой оптимизации
```

## Как посмотреть
Открыть любой файл из `demo/` в браузере (двойной клик). Стили и изображения
подтягиваются с боевого сайта, поэтому страница выглядит как реальная, но уже с
оптимизацией. SEO-текст внизу разворачивается по кнопке «Читать полностью».

## Что оптимизировано (сводка по аудиту)
Полный обход всех **68 831** URL выявил и в шаблонах устраняется:
- **Product/Offer микроразметка** — была на 0 из 65 919 карточек → добавляется в шаблон;
- **meta description** — 91,5% длиннее нормы → шаблон ≤160 символов;
- **title** — 57% длиннее 60 символов → шаблон ≤60;
- **alt у изображений** — ~1 млн без alt → автогенерация из полей товара;
- **дубли H1** → один H1 на страницу;
- **1 296 битых URL в sitemap** (404/410) → чистка карты;
- **SEO-тексты** — тонкие/шаблонные → развёрнутые тексты с таблицами и 8 FAQ, перелинковка.

Подробности и план — в [`docs/SEO-STRATEGY.md`](docs/SEO-STRATEGY.md).
