# Навык: SEO-оптимизация myarredo.by

## Когда применять
Оптимизация любой страницы myarredo.by (карточка/категория/главная): мета, разметка,
alt, SEO-текст, перелинковка — по единому шаблону в фирменном стиле сайта.

## Правила контента
- **Только достоверные факты.** Бренды, материалы, фурнитуру берём из полей
  страницы; дизайнеров/коллекции — только если подтверждено (WebSearch). Не выдумывать.
- **Каркас Lotus и подобных** — уточнять по источнику (у ARKETIPO Lotus: металл+фанера,
  наполнение ППУ+пух, дизайн Manzoni e Tapinassi).
- **Тон** — экспертный магазин, русский язык, без эмодзи.

## Формулы мета
- title ≤ 60: товар — `{тип} {бренд} {коллекция} — купить в Минске | Myarredo`;
  категория — `Итальянские {категория} в Минске — из Италии | Myarredo`.
- description ≤ 160: суть + гео + «под заказ/доставка по Беларуси».
- canonical — абсолютный URL страницы.

## Структура SEO-блока (класс-контракт)
`<section class="seo-desc" id="seoDesc">` → `<h2>` + лид-`<p>` →
`<div class="seo-rest" id="seoRest">` c: `<h3>` + `<ul class="adv">` (6),
3–4 таблицы `<div class="tbl-wrap"><table class="data">…`, «Стандарты» (ГОСТ 16371-2014,
19917-2014, ТР ТС 025/2012; для света — ГОСТ IEC 60598-1, ТР ТС 004/2011),
«Где используется», «Смотрите также» `<div class="links">` (только живые URL),
`<div class="faq-grid">` c **ровно 8** `.faq-card` (2 колонки), `<div class="tags">` →
кнопка `<button class="seo-toggle" id="seoBtn" onclick="…toggle open…">`.
Стили — из `templates/category-seo.css.html` (зелёный акцент #3aa34a, PT Sans).

## Schema.org
Product + Offer (priceCurrency BYN, availability PreOrder для «под заказ»),
BreadcrumbList, FAQPage (совпадает с видимыми 8 FAQ), ItemList на категориях.

## Перелинковка
Блок «Смотрите также» — 5–7 ссылок на смежные разделы/бренды. **Проверять статус
200 перед вставкой** (на сайте ~1300 битых URL; напр. /factory/calligaris/ = 404).

## Пайплайн (toolkit/)
1. `crawl.mjs` — обойти sitemap, собрать метрики.
2. `aggregate.mjs` — сводка проблем.
3. Сгенерировать SEO-блок под раздел (данные из полей + WebSearch по брендам).
4. `build-demo-pages.mjs` — собрать страницу (fetch + инъекция блока + мета).
5. Отдать фрагмент для вставки в CMS-шаблон (авто-подстановка из полей → все страницы).

## Заголовки запросов (антибот nginx)
Требуются навигационные заголовки (Sec-Fetch-*, Referer, Upgrade-Insecure-Requests) —
см. `toolkit/headers.mjs`; кастомный User-Agent даёт 403.
