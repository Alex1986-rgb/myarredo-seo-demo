# SEO-стратегия вывода myarredo.by в топ

Комплексная оптимизация по всем направлениям. Основной принцип — **шаблонные
правки в CMS**, автозаполняемые из полей товара/раздела, поэтому одно изменение
покрывает десятки тысяч страниц.

## 1. Техническое SEO
- **Canonical** на всех типах страниц (есть на 99,8% — добить оставшиеся 122 URL).
- **Один H1** на страницу (устранить дубли: было по 2 на категориях/главной/карточках).
- **title ≤ 60**, **meta description ≤ 160** — формулы в шаблонах:
  - товар: `{тип} {бренд} {коллекция} — купить в Минске | Myarredo`
  - категория: `Итальянские {категория} в Минске — из Италии | Myarredo`
- **/sitemap.xml** → 301 на реальный индекс `/sitemap/sitemap_minsk.xml`.
- **Чистка sitemap**: убрать 1 296 битых URL (1 048×404 + 248×410), для удалённых
  товаров — 410 + 301 на аналог/категорию (список в аудите).
- **HSTS**: добавить `Strict-Transport-Security` в nginx.
- **Скорость/CWV**: `loading="lazy"` для изображений вне первого экрана, WebP/AVIF,
  сжатие (gzip есть; рассмотреть brotli).

## 2. On-page и контент
- **SEO-тексты** на карточках и категориях: развёрнутые, с H2/H3, **таблицами**
  (материалы, фурнитура, наполнение, цвета, механизмы) и **8 FAQ** в 2 колонки.
  Конкретика: итальянские дизайнеры, коллекции, бренды, кожа/ткань, ГОСТ/ТР ТС.
- **Сворачиваемый блок** (виден лид-абзац, стрелка разворачивает) — держит текст
  на странице для SEO, не ломая UX.
- **Верхнее описание карточки** — 2 абзаца + таблица «Характеристики»
  (фабрика, дизайнер, коллекция, каркас, наполнение, обивка, размеры, артикул).

## 3. Изображения (попадание в поиск по картинкам)
- **alt** всем изображениям по шаблону `{тип} {бренд} {коллекция} арт. {sku}` —
  автогенерация из полей товара (сейчас ~1 млн изображений без alt).
- Осмысленные **имена файлов** (транслит бренда/модели вместо хэшей).
- **ImageObject** в разметке товара; sitemap изображений.
- WebP/AVIF, корректные размеры, `width/height` для стабильного layout.

## 4. Микроразметка Schema.org (rich snippets)
- **Product + Offer** на карточках (цена/наличие/валюта BYN) — сейчас 0% → в шаблон.
  Для «под заказ» — `availability: PreOrder`, цена из БД.
- **AggregateRating** при наличии отзывов.
- **BreadcrumbList** (есть на 99,9% — оставить), **FAQPage** (из блока 8 FAQ),
  **Organization/LocalBusiness** (реквизиты, адреса салонов), **ItemList** на категориях.

## 5. Перелинковка
- В каждом SEO-блоке — блок «Смотрите также» на смежные разделы и бренды
  (только живые URL — проверять статус перед публикацией).
- Хлебные крошки, ссылки бренд↔категория↔товар, related-товары.

## 6. Локальное SEO (Беларусь)
- Гео-ключи «в Минске», «по Беларуси», города-поддомены (brest, vitebsk…).
- **hreflang** между версиями (.by/.uk/.com-it/.de/.fr + региональные поддомены) + x-default.
- Яндекс.Вебмастер + Google Search Console, Яндекс.Бизнес/Карты, отзывы.

## 7. AI / GEO (выдача в AI-ответах)
- Чёткие FAQ и таблицы фактов (их любят цитировать LLM/AI Overviews).
- `llms.txt`, структурированные данные, однозначные формулировки характеристик.

## 8. Приоритеты внедрения
1. Product/Offer + FAQPage в шаблон карточки (максимальный эффект на CTR).
2. Формулы title/description ≤ нормы во всех шаблонах.
3. alt-автогенерация для всех изображений.
4. Чистка sitemap от 404/410; /sitemap.xml редирект.
5. Развёрнутые SEO-тексты по категориям и типам товаров (шаблон + генерация из полей).
6. hreflang, HSTS, lazy-load, единый H1.

## Инструменты аудита (toolkit/)
- `crawl.mjs` — полный обход sitemap (статусы, alt, canonical, title/desc, H1, Schema).
- `aggregate.mjs` — сводка по всему сайту (что и на скольких страницах чинить).
- `build-demo-pages.mjs` — генерация оптимизированных страниц из шаблонов.
